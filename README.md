### 🚀 What I'm building

I build spec-first. Every repo I own has a `SPEC.md` at the root, and I work with Claude through a plan, build, test, review loop to turn specs into shipped code.

### 🛠️ Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**hardware-bringup**](https://github.com/itsnicoramos/Spec-to-ship) | A Claude Code skill that stops coding agents from claiming hardware works when they've never seen it. Host-tested logic, bench cards for the human, and a phone console for logging readings. In use on a 4-DOF Arduino arm. | Claude Code, Next.js, TypeScript, Supabase |
| [**ChainMind**](https://github.com/itsnicoramos/ChainMind) | A purpose-built blockchain with a conversational AI agent as the main interface. Chat or talk to your chain to mine, send coins, and automate rules. | Python, FastAPI, SQLite, Claude API, Web Speech API |
